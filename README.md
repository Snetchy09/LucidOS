# LucidOS

LucidOS is a desktop operating system that I have been building. LucidOS contains built in applications, a desktop app launcher, a file system, a login system and a programming language named Lucid script. it lets users create applications that run inside LucidOS. I also plan to support programming languages in future versions of LucidOS.

## Features

LucidOS has built‑in apps:
  terminal: a terminal with commands for creating and editing files
  
  calculator : a simple calculator for basic math

  browser : a web browser , Many websites block displaing in an iframe so only Wikipedia works

  notes: a simple notes app where you can save recipies, ideas or important information

  text editor : edit and save text files

  files : access your LucidOS files, including drawings, music and installed apps

  calendar: save events and special days

  Lucid paint: a drawing app with both pixel and smooth drawing modes, as well as an animation mode

  Lucid media: a music app where you can play music and create cool beats!

  Lucid store: browse apps install them and rate them. community made apps will come as soon as LucidOS have users

  Lucid studio: create simple games and applications using Lucid script, you can keep your apps for yourself or Publish them for a chance to have them appear in the Lucid store! more programming language support is planned

  settings: change to a custom wallpaper, switch between light and dark mode,  manage your account and subscription information and check your app submissions status, and uninstall apps or erase your storage.

LucidOS also has some features that make it different from a normal OS since the orb acts as the start menu and desktop icons can be dragged around freely without a grid and users can create their own applications inside LucidOS

## Used Providers

  Supabase : auth and store database

  Backblaze: storing published Lucid store apps (warehouse)

  Vercel: publish API

  Lemon Squeezy: payment system

  Resend: custom cool emails

## How I Built It

I built LucidOS as a way to experiment with making a desktop completely inside a browser , I worked on the desktop, launcher, file system, applications, Lucid script, Lucid studio, authentication, app publishing and the services used by the store, A lot of the work was also testing the project finding bugs changing things that did not work well and trying ideas for how LucidOS should feel
I used AI tools during development, including for parts of the code and for debugging. I still did the project setup, feature decisions, testing, and the overall direction of LucidOS myself
